# Brutal Verdict

If you build this correctly in Rust:

* Static binary: **10–30 MB** realistic
* Idle RAM: **20–50 MB**
* Small VPS support: **1 vCPU / 512 MB RAM**
* Comfortable production: **1 vCPU / 1 GB RAM**
* Hundreds of deployments manageable without significant overhead

The real resource consumption will come from **Docker containers, image builds, logs, and applications**, not from the Rust control plane itself. Your platform runtime should be able to stay under **50 MB idle RAM** and near-zero CPU if you avoid embedding heavyweight observability and UI stacks.

# Anti-Feature Validation

For every proposed feature answer:

What problem does it solve?

Who requested it?

How often will it be used?

What happens if it is never built?

Can an existing tool solve it?

Does it increase operational complexity?

Would a solo developer benefit?

Would a startup benefit?

Reject features that fail validation.
