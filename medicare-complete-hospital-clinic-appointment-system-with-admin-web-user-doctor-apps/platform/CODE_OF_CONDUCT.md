# Code of Conduct

Kelson follows the Contributor Covenant v2.1.

## Our standard
Be direct, be kind, assume competence. Critique code, not people.

## Enforcement
Report incidents to the maintainers (`conduct@kelson.invalid` placeholder).
Reports are confidential. Enforcement ranges from warning to permanent ban,
proportionate to the behavior.
