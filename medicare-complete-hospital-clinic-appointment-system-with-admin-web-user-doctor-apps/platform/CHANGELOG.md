# Changelog

All notable changes to the Keel platform are documented here.
Generated by [git-cliff](https://git-cliff.org) from Conventional Commits.

## [Unreleased]

### Features

- *(http)* Wave 1 named middleware chains (Laravel `$middlewareGroups`
  parity): root `middleware.toml` discovery file (`[aliases]`, `[groups]`,
  `[throttle.<group>]` bucket configs) over a builtin catalog with the
  implicit `api` group (`throttle:api` -> `auth` -> `verified`), `public`
  stripping auth/verified only, per-route chain execution at the dispatch
  edge, and the fail-closed `GRAPH-MW-UNKNOWN` boot gate (collect-all).
- *(http)* Route model binding: `route.bindings` registry service with
  per-model resolvers registered at boot (`GRAPH-BINDING-RESOLVER` gate);
  the edge injects `_bindings.<param>` after the path/query/body merge so
  bodies cannot forge bindings; malformed id / miss / cross-tenant all 404.
- *(http)* Pagination injection: GET graph routes parse `page`/`per_page`
  (clamped to `MAX_PER_PAGE` 100; `page=0` -> 422) and inject `_page`;
  appointments `list` emits the `page` meta block (page, per_page, total,
  has_more).
- *(http)* Manifest FormRequest validation at the edge: `[[validation]]`
  specs run collect-all before CommandBus dispatch (422 envelope with
  `fields` meta); the `date` rule accepts minute-precision timestamps.
- *(http)* Deprecated routes (`deprecated = true`) emit `Deprecation: true`
  header + envelope meta (L72); anonymous reach is restricted to public
  routes whose handler plan opts out of authorization.
- *(http)* `TypedHandler<I, O>` typed bridge (keel-command) plus
  `Validated`/`Resource` view-model adapters (keel-http) as the opt-in
  typed dispatch pattern.
- *(cli)* `keel route:cache` / `keel route:clear`: write/delete the pinned
  route artifact `storage/framework/routes.json` (resolved chains, bindings,
  validators + manifest content hash + `MODULE_ABI`); boot always recompiles
  the graph and refuses a stale or corrupt artifact (stricter than Laravel).
- *(cli)* `keel check` now also compiles the platform graph and resolves
  every route's middleware chain (`GRAPH-MW-UNKNOWN`).
- *(codegen)* OpenAPI emission carries `[[validation]]` constraints
  (required, minLength/maxLength, minimum/maximum, enum via one_of, format
  hints) and native `deprecated: true`.

### Testing

- *(http)* `http_integration` Wave 1 battery: 422 field meta, public vs
  authenticated reach, binding miss/malformed/cross-tenant 404 + cancel on
  hit, pagination clamp + `page=0` 422, deprecation header/meta, throttle
  429 + Retry-After.

### Changed

- *(workspace)* **Wave 2 crate renames** (crates.io name-squat recovery):
  `keel-core` → `keel-foundation`, `keel-sessions` → `keel-session`,
  `keel-events` → `keel-event`, `keel-cli` → `keel-console` (directory moved
  `tools/keel-cli` → `tools/keel-console`; `[[bin]] name = "keel"` unchanged).
  Package names, workspace dependency keys, member manifests and every import
  (`keel_core` → `keel_foundation`, etc.) were swept together, plus the doc
  references in `platform/docs/*`, `platform/PUBLISHING.md`, `docs/rust/*`.
  The `publish = false` gate and the Wave 2 comment are removed from all four
  manifests, unblocking the Wave 2 publish wave.

### Fixed

- *(clippy)* `too_many_arguments` on `MiddlewareCatalog::validate_route` — the
  seven per-route parameters collapsed into a `&RouteSpec` (single caller).
- *(clippy)* `ptr_arg` on `apply_groups` (`&mut Vec<RouteSpec>` → `&mut [RouteSpec]`),
  `doc_lazy_continuation` on the `RouteSpec::constraints` doc, and
  `explicit_counter_loop` in the views parser (`starts`).

## [0.1.0] - 2026-08-22

### Features

- *(release)* First public crate: **keel-analyzer 0.1.0** — architecture
  analyzer enforcing the platform dependency matrix (gate G07).

### Build

- *(release)* Release-engineering groundwork: crates.io metadata
  (repository/readme/keywords inheritance, docs.rs config), per-crate READMEs,
  MIT + Apache-2.0 license files, versioned internal workspace dependencies,
  and `publish = false` gating for internal-only and Wave-2-blocked crates.
- *(release)* `xtask publish` (topologically ordered, retries, dry-run,
  `--only` subset, machine-readable summary for CI) and `xtask bump`
  (lockstep version bump with count validation).
- *(release)* Supply-chain gate: `deny.toml` (cargo-deny v2) — advisory,
  license, ban, and source policies with a documented MPL-2.0 exception.
- *(release)* `keel-publish.yml` workflow: ubuntu+windows verify matrix,
  MSRV 1.85 check, cargo-deny, semver gate, publish, registry smoke test,
  release tag `keel/platform-vX.Y.Z`, changelog regeneration.
- *(release)* Continuous publishability signal (`publish --dry-run`) on the
  main branch in `keel.yml`.
- *(release)* Conventional Commits convention + git-cliff changelog
  automation (`cliff.toml`, `just changelog`).

### Documentation

- *(release)* `PUBLISHING.md` (release flow, token hygiene, wave status,
  bump/yank/troubleshooting) and `runbooks/keel-release.md` checklist.
