## [Unreleased]

### Security

- **21 RUSTSEC advisories resolved in the supply-chain gate.** `wasmtime` 34.0.2
  → **36.0.17** (36.0.16 is the lowest version whose patched range covers *every*
  wasmtime advisory — each is `>=36.0.x, <37.0.0`, so 37.0.2 would not have
  sufficed) and `rustls` 0.23.43 → **0.23.45**. The single advisory with no
  upstream fix, `RUSTSEC-2023-0071` (`rsa`, RustSec `patched = []`, reached only
  transitively via sqlx-mysql), is recorded as an explicit governance note in
  `deny.toml` rather than silently ignored. `cargo deny check` now exits **0**
  (`advisories ok, bans ok, licenses ok, sources ok`) from both `platform/` and
  `keel-platform/`, unblocking the `deny` job that gates `publish`.

### Added

- **`tenant-ports` feature flag on `keel-caching` and `keel-storage`** (§9 box
  *"tenant-scoped port traits … behind feature flags"*). The tenant layer —
  `TenantCachePort` / `TenantStoragePort`, their `…Shard` adapters, the
  `MapStore` test substrate and the 9 tenant tests — is now behind
  `#[cfg(feature = "tenant-ports")]`, **default ON**, so no normal build
  changes behavior. `keel-tenancy` requests the feature **explicitly** on both
  dependencies rather than inheriting that default, so a
  `--no-default-features` rebuild cannot silently drop §3.2. The OFF state is
  executable, not decorative: `cargo check … --no-default-features --tests`
  exits 0 with zero errors *and* zero warnings, and provably removes tests —
  `keel-caching` **17 → 13**, `keel-storage` **11 → 6** — while the full
  default suite is unchanged at **141 suites / 1244 passed / 0 failed**.

### Changed

- **BREAKING — MSRV 1.85 → 1.88 (`platform`) / 1.89 (`keel-platform`,
  `keel-kernel`, `your-app`).** wasmtime 36 declares `rust-version = 1.86.0`
  (34.x had been the deliberately "MSRV-aware" line), but that is only the floor
  wasmtime imposes — the lockfiles decide the real one. 1.86 is rejected outright
  by cargo for `home`, `icu_*`, `time` and `wasm-{encoder,wast,wat}` 261 (all
  requiring 1.88), and `uuid 1.27.0` ("requires rustc 1.89.0") pushes the three
  non-platform roots to 1.89; `platform` resolves the older `uuid 1.24.1` and
  stops at 1.88. Each floor is verified by a real `cargo check --workspace
  --locked` on that exact toolchain. Updated in all four workspace roots,
  `DEPENDENCY-POLICY.md` and `docs/01-GETTING-STARTED.md`.
- **The `msrv` CI gate was a silent no-op; it is real now.**
  `platform/rust-toolchain.toml` pins channel 1.92.0 and rustup resolves that file
  *above* `rustup default`, so installing 1.86.0 and setting it as the default
  still built 1.92.0 — the job reported the floor as met without ever testing it.
  It now sets `RUSTUP_TOOLCHAIN` (which outranks the file, verified by resolving
  1.92.0 normally and 1.86.0 with the variable set) and runs a per-workspace
  matrix, one leg per verified floor.
- **CI: one pipeline split into four.** `.github/workflows/keel.yml` now has a
  job per Cargo workspace with its own `working-directory` and target cache. The
  original single `foundation` job ran only against `platform`, whose `members`
  exclude `keel-platform`, `keel-kernel` and `your-app` — all three were
  previously untested by CI.

### Features

- *(http)* Wave 1 named middleware chains (Laravel `$middlewareGroups`
  parity): root `middleware.toml` discovery file (`[aliases]`, `[groups]`,
  `[throttle.<group>]` bucket configs) over a builtin catalog with the
  implicit `api` group (`throttle:api` -> `auth` -> `verified`), `public`
  stripping auth/verified only, per-route chain execution at the dispatch
  edge, and the fail-closed `GRAPH-MW-UNKNOWN` boot gate (collect-all).
- *(http)* Route model binding: `route.bindings` registry service with
  per-model resolvers registered at boot (`GRAPH-BINDING-RESOLVER` gate);
  the edge injects `_bindings.<param>` after the path/query/body merge so
  bodies cannot forge bindings; malformed id / miss / cross-tenant all 404.
- *(http)* Pagination injection: GET graph routes parse `page`/`per_page`
  (clamped to `MAX_PER_PAGE` 100; `page=0` -> 422) and inject `_page`;
  appointments `list` emits the `page` meta block (page, per_page, total,
  has_more).
- *(http)* Manifest FormRequest validation at the edge: `[[validation]]`
  specs run collect-all before CommandBus dispatch (422 envelope with
  `fields` meta); the `date` rule accepts minute-precision timestamps.
- *(http)* Deprecated routes (`deprecated = true`) emit `Deprecation: true`
  header + envelope meta (L72); anonymous reach is restricted to public
  routes whose handler plan opts out of authorization.
- *(http)* `TypedHandler<I, O>` typed bridge (keel-command) plus
  `Validated`/`Resource` view-model adapters (keel-http) as the opt-in
  typed dispatch pattern.
- *(cli)* `keel route:cache` / `keel route:clear`: write/delete the pinned
  route artifact `storage/framework/routes.json` (resolved chains, bindings,
  validators + manifest content hash + `MODULE_ABI`); boot always recompiles
  the graph and refuses a stale or corrupt artifact (stricter than Laravel).
- *(cli)* `keel check` now also compiles the platform graph and resolves
  every route's middleware chain (`GRAPH-MW-UNKNOWN`).
- *(codegen)* OpenAPI emission carries `[[validation]]` constraints
  (required, minLength/maxLength, minimum/maximum, enum via one_of, format
  hints) and native `deprecated: true`.

**Wave 2 — routing completion, web plane, views, request/response, errors, assets:**

- *(routing)* Route planes and edge dispatch (Laravel routing parity):
  `plane = "api"|"web"` per route/group/root route file, verb dispatch with
  auto-HEAD (body stripped, 8 MiB cap), auto-OPTIONS with `Allow`, 405 +
  `Allow` on verb mismatch, `method = "ANY"` expanding to the full verb set
  at registration, `RouteGate` host/domain/subdomain matching before `auth`,
  signed + temporary/one-time signed URLs (HMAC-SHA256; fail-closed 500
  without `app.key`, spent link -> 404), parameter constraints as a routing
  predicate (closed kinds + pattern mini-grammar, no regex crate; mismatch ->
  404), and `[url] defaults` for `resolve_url`.
- *(registry)* Root route files (`routes/web.toml`/`routes/api.toml` merged
  at boot, `GRAPH-ROUTEFILE-OP`), `[[route_groups]]`
  prefix/middleware/plane inheritance (`GRAPH-GROUP-UNKNOWN`,
  `GRAPH-FALLBACK-DUP` max-one-per-plane), resource/singleton expansion
  (`resource`/`apiResource`/`singleton` shapes with `only`/`except` verb
  filters), `UrlSection` URL defaults — all parse-time with collect-all
  boot gates.
- *(views)* `keel-views` template engine: interpreted AST, full
  Blade-familiar directive ledger (`@extends`/`@section`/`@yield`/`@parent`,
  `@include*`, `@component`/`@slot`/`@props`, `@if`/`@unless`/`@foreach`/
  `@for`/`@forelse`, `@once`/`@push`/`@stack`, `@csrf`/`@method`/`@error`/
  `@lang`/`@js`, attribute helpers), custom directive + conditional
  registries, package namespace resolver, compiled-AST cache (mtime +
  content hash); `@php`/`@while` refused as SUPERSEDED (no PHP eval).
- *(http)* HTML routes (`response = "html"` renders the declared view with
  the operation result as context) and web-plane error rendering (error
  views for HTML clients, envelope for JSON, RFC-7807 `problem+json`
  opt-in, `app.debug` gate hides internals).
- *(http)* Response kinds at the edge: `json` (default envelope), `html`,
  `redirect` (validated status + one-request flash), `download`/`file`
  (StoragePort attachment, sanitized filename), `stream` (chunked NDJSON
  flush), `no_content`; plus per-route `Cache-Control` policy with
  ETag/conditional-GET 304.
- *(http)* Static assets for `public/`: percent-decoded path resolution,
  traversal refusal, canonicalized prefix check, fingerprinted files get
  `immutable` (else `no-cache`), Vite `manifest.json` reader + `@asset`
  directive, not-found fallback rendering the error view or envelope.
- *(cli)* `keel route:list --name/--path/--plane` filters (case-insensitive
  substring, validated plane) with plane/group/version/deprecation columns,
  and the `keel view:cache` / `keel view:clear` compiled-view artifact
  cycle.

**Wave 3 — Eloquent & query parity + API resources:**

- *(query)* Full read-builder surface in `keel-query`: clause tree
  (Junction/Clause) with recursive bind-continuous rendering — `or_where`
  family + nested groups, `where_not_in`, between/not-between, column
  comparisons, `where_like` (ILIKE), date/year/month/day/time, correlated
  `where_exists`/`where_not_exists`, keyset row comparison, `distinct`,
  projection batches, `latest`/`oldest`, `lock_for_update`/`shared_lock`,
  `group_by`/`having` (+ HAVING-only guard), `union`/`union_all`, and
  `count/sum/avg/min/max/exists/doesnt_exist` (33 rendering tests;
  keel-query compiles SQL but never executes it — documented divergence).
- *(models)* Eloquent finders & mutations on `ModelRuntime`: `get`/
  `first_or_not_found` (typed `KER_NOT_FOUND`), `first_or_create`,
  `first_or_new`, `update_or_create`, `force_create`, `create_many`,
  `insert_get_id`, `insert_or_ignore`, `update_or_insert`,
  `increment`/`decrement` (atomic, CAS-exempt by design), `replicate`,
  `refresh`, `fresh`, `load_missing`, `touch`, `push` (insert-or-update
  of the record + loaded relations, depth-capped) and lazy execution
  methods `pluck`/`value`/`chunk`/`each`/`cursor`.
- *(models)* Relation parity: eager aggregates (`with_count`/`with_sum`/
  `with_min`/`with_max`/`with_avg`), existence filters (`has`,
  `doesnt_have`, `or_where_has` + `where_relation`), nested `with` paths
  with per-level constraints, pivot ops (`attach`/`detach`/`sync`/
  `toggle`/`update_existing_pivot`), polymorphic eager loading over the
  morph map.
- *(models)* Casts, visibility & strict mode: builtin cast set + custom
  `with_cast` registry (validated at set time), fail-closed `encrypted`
  sealer, fresh-salt `hashed`, projection control (`wire`,
  `make_visible`, `make_hidden`, manifest `hidden` precedence,
  `public_record` redaction), strict guards (lazy-load / discarded /
  missing attributes) and `RecordChanges` dirty tracking.
- *(models)* Soft deletes, scopes & optimistic locking: `find_trashed` /
  `with_trashed` / `only_trashed` / `restore` / `force_delete`, route
  binding `with_trashed`, global scopes (`with_global_scope`,
  `without_global_scopes`), `version_column` CAS (`STALE_RECORD` → 409),
  `without_timestamps`, and `PruneRegistry` chunked pruning.
- *(cli)* `keel model:prune` — sweeps prunable models in chunked passes
  (`--chunk`, `--tenant`; untenanted by default).
- *(http)* Typed `Resource` transformer trait (Laravel `JsonResource`
  parity): `from_source` bodies, `when`/`when_some` conditional fields
  (omission, never null), wrapping key (default `data`),
  `ResourceCollection` list/page rendering with pagination-meta
  passthrough (`envelope_resource_page`); the typed-bridge struct is
  renamed `Resource` → `TypedResource`.
- *(codegen)* `make resource` emits a compiling
  `impl keel_http::Resource for XResource` skeleton (the old template
  implemented a struct as a trait and could never build).

**Wave 4 — Validation expansion + config + cache + parity residuals:**

- *(validation)* ~45 new rules over the manifest grammar: types, strings,
  numeric (incl. field refs), conditionals, cross-field, dates, file
  metadata, composable `password` + `current_password`, and tenant-scoped
  `unique`/`exists` ModelStore probes (DB error → 503, never a pass);
  `bail` short-circuit, dot-path wildcards (`items.*.name`), custom
  per-field messages; boot-refusing collect-all gates
  `GRAPH-VALIDATION-RULE`, `GRAPH-VALIDATION-FIELD`, `GRAPH-RULE-UNKNOWN`
  (unregistered custom name).
- *(config)* `PlatformConfig::freeze()` (Arc, getters only) consumed by
  boot; `GRAPH-CONFIG-SCHEMA` refuses unknown config keys; the xtask env
  lint fails on `std::env::var` outside sanctioned boot paths;
  `keel env`, `keel config:cache` / `config:clear` /
  `config:show <key> [--json]` (hash-pinned drift-refuse boot check,
  secrets redacted), `keel cache:forget`.
- *(cache)* `CacheService` over the unchanged `CachePort`: `remember` /
  `remember_forever` (stampede single-flight with jittered wait), atomic
  `add`, `forever`, `pull`, `many`/`put_many`, counters, `flush`; cache
  tags (memory = prefix namespaces, Redis = SET membership); atomic locks
  with a closure form. Values serde_json-serialized at the service layer —
  `keel-caching` gains the workspace-budgeted `serde_json` dependency
  (crate-level addition, no budget change).
- *(auth)* Session remember-me: `remember: bool` on login → cookie
  `Max-Age = SessionPolicy.remember_ttl` (30d default) + bag flag,
  preserved across regeneration, reported by `/auth/me`; `POST
  /auth/confirm` re-verifies the password and stamps `confirmed_at`, the

  Honest gaps: cookie-`Max-Age` only (server-side idle/absolute session
  bounds unchanged); the web-plane confirm redirect was not implemented —
  both planes answer the envelope (same precedent as `verified`).
- *(cli)* `keel about` (Laravel-style environment report) and `keel
  profile api|worker` (out-of-process samply wrapper; missing samply fails
  closed with the install line + the docs/13 workflow).
- *(registry)* `GRAPH-VERSION-SEMVER` gate: route `version` parses as
  `v<N>` and agrees with any version-looking path segment; OpenAPI carries
  the per-route `x-keel-version` extension beside `deprecated: true`.
- *(shell)* `keel shell` gains `caps` (declared capability catalog +
  session grants) and `models` (binding/probe registries) introspection.
- *(testing)* Playwright smoke kit `templates/starter-template/e2e/`
  (own package.json, external tooling): auth register/login + notes
  create/list against `keel serve`; documented in 11-TESTING, CI-optional
  and executed out-of-band.

**Wave 5 — Command & generator surface:**

- *(cli/optimize)* `keel optimize` warms route → config → view artifacts
  in order and aborts at the first refusal; `keel optimize:clear` drops all
  three, attempting every step (a failed delete never strands one cache).
- *(migrations)* Revertible pair migrations (`<ts>_<name>.up.sql`/
  `.down.sql`) tracked in the `keel_migrations` bookkeeping table (each
  apply = one batch, bookkeeping commits transactionally with the SQL):
  `keel migrate:rollback [--step n]` (default 1; batches newest-first,
  reverse filename order; forward-only singles untouched and said so),
  `migrate:reset` / `migrate:refresh [--step n]` (dev/test-only),
  `migrate:install`; fixtures in `database/migrations-pairs/`. `migrate`
  now takes `pg_advisory_lock(7259)` before any run and fails closed on
  timeout — concurrent migrators serialize.
- *(cli/db)* `keel db:show` (driver, server version, database + inventory)
  and `keel db:schema:dump` (normalized DDL snapshot →
  `database/schema.sql`; honest marker for an empty schema).
- *(cli/queues)* `keel queue:clear` (pending purge; refuses prod/staging,
  `KEEL_FORCE=1` to script), `queue:flush` (unbounded dead-job purge),
  `queue:forget <id>`, `queue:monitor` (depth + oldest-age render),
  `queue:prune-failed --hours 168`, `queue:prune-batches --hours 72`,
  `queue:restart` (signal file; workers ignore a signal older than their
  start), `queue:listen` (supervisor: respawn on exit with crash-loop
  backoff), `queue:retry-batch <id>` (id-validated, fails closed until the
  batch ledger persists — B-32).
- *(cli/storage)* `keel storage:link [--force]` — `public/storage` → the
  local disk root; refuses to overwrite without `--force`, never deletes a
  real directory.
- *(cli/testing)* `keel test [--pg]` — runs `cargo test --workspace
  --locked`, tallies `test result:` lines into a PASS/FAIL verdict;
  `--pg` adds `--features pg-tests` and fails closed without
  `DATABASE_URL`.
- *(cli/console)* `keel call <name> [json] [--principal <uuid>]
  [--tenant <uuid>]` over `routes/console.toml`: pre-flight resolves the
  operation (list on miss), default operator = first active principal in
  dev/test only (production needs `--principal` — B-33), tenant falls back
  to the dev/test default (production has none — pass `--tenant`), then
  `keel-api --call` dispatches through the CommandBus + policy engine
  (capability denial enforced; the HTTP edge-stage validation layer is not
  re-run).
- *(cli/schedule)* `keel schedule:work [--every n]` daemon (fires due
  items as durable jobs, persists last-fired state, exits before the DB on
  an empty registry) and `keel schedule:test` (pure dry run) over the
  deliberately empty `schedule_registry()` seam; `schedule:list` /
  `schedule:run` remain information stubs (module schedules land Wave 6).
- *(codegen)* `GENERATOR_KINDS` 15 → 27: cast, channel, component,
  exception, mail, notification, observer, rule, scope, job-middleware,
  middleware, view — each template points at real platform surface
  (`keel_models::Cast`/`ModelObserver`, `register_custom_rule`,
  `FieldFilter` scopes, `AppError` conversions, the axum `from_fn` shape,
  `keel_jobs::{BoxFuture, DurableJob}`, real view-root paths). Honest
  partials: mail/notification definitions are standalone (Wave 6
  dispatch), job-middleware composition is Wave 6, channel auth is Wave 6.

- *(notifications)* `NotificationDef` typed notifications with
  per-channel renderers (`to_mail`/`to_sms`/`to_push`/`to_database` +
  the `template` seam) dispatched through
  `NotifyHub::dispatch_notification`; the framework `notifications`

  `AppointmentBooked`/`AppointmentCancelled` in the request locale

- *(storage)* `[storage] default` + `[storage.disks.<name>]` disk

- *(i18n)* fail-closed `lang/<locale>.toml` boot loader feeding the
  `MessageCatalog` (shipped en/fr/ar), locale resolution session →
  quality-ordered `Accept-Language` → configured default, `@lang` /

- *(scheduler)* zero-dep 5-field cron parser (`*`, lists, ranges,
  steps; invalid/never-firing expressions refuse registration) + builder
  helpers (`hourly`/`daily`/`daily_at`/`weekly`/`monthly`/
  `every_minutes`); per-item IANA timezone validated against a bundled
  static table (fixed offsets — documented no-DST limitation);
  `without_overlapping`/`on_one_server` guards over the `ScheduleLock`
  port (in-process default, cache-backed in the worker);
  before/after/on_success/on_failure hooks with failures recorded in
  the tick state.
- *(broadcast)* `POST /api/v1/broadcast/auth` issues a 300-second
  `TokenPurpose::Channel` token against the boot-resolved
  `routes/channels.toml` capability gate (unknown channel and ungranted
  capability share one 403); `GET /api/v1/broadcast/members` presence
  roster under the same gate; host-side `ChannelTokenAuthorizer`
  validates every `/realtime/sse|ws` connect (uniform 401; a token
  never grants more than its channel).
- *(jobs)* queue admission plane: `unique_key`/`unique_ttl_secs`
  (cache-lock admission — held elsewhere defers the claim, released on
  success), `rate_limit` token bucket (exhausted → hold until refill,
  never a failure), `JobMiddleware` + `MiddlewareStacks` (built-ins
  unique → rate-limit → retry-limit before module layers, frozen at
  first dispatch) with `retry_limit`, `JobStoreAdmin::defer`/`kill`,
  `ChainRuntime` failure-position recording, and the `/metrics` queue
  depth/age/throughput census.
- *(batches)* durable batch ledger (B-32): `BatchLedger`
  (memory/Pg over `20261001000002_job_batches.sql`; membership written
  once before enqueue); `BatchOps::{status,cancel,retry}` over the live
  job store; capability-gated `GET/POST /api/v1/batches/{id}` endpoints
  (`batches.status`/`batches.cancel`/`batches.retry`);
  `queue:retry-batch`/`queue:prune-batches` run the real ledger.
- *(http client)* `ReqwestHttpClient` parity: retry schedule
  `{times, base_ms, max_ms, on}` (serde-default with the original
  all-four posture; unknown condition refuses the build; `retry_on`
  gates retrying only — an excluded 5xx fails fast with the same
  `EXT_ERROR` shape), per-request `timeout_ms`, bounded `execute_pool`
  (input order, panic-safe slots), redacted `HttpTap` hooks (bodies
  never logged), `HttpFake` assertions (Wave 7 testkit names), and
  streaming `sink_to` over `StoragePort::writer` (non-2xx →
  `EXT_ERROR`, no retry mid-stream, partial file removed locally).
- *(honest gaps)* no multipart/streamed request bodies on the HTTP
  client; the `s3` disk driver stays the in-memory sandbox (program
  decision); cron is numbers-only (no `MON`/`?`/`L`/`#`, no seconds
