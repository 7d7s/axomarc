# Changelog

All notable changes to the Keel platform are documented here.
Generated by [git-cliff](https://git-cliff.org) from Conventional Commits.

## [Unreleased]

### Features

- *(http)* Wave 1 named middleware chains (Laravel `$middlewareGroups`
  parity): root `middleware.toml` discovery file (`[aliases]`, `[groups]`,
  `[throttle.<group>]` bucket configs) over a builtin catalog with the
  implicit `api` group (`throttle:api` -> `auth` -> `verified`), `public`
  stripping auth/verified only, per-route chain execution at the dispatch
  edge, and the fail-closed `GRAPH-MW-UNKNOWN` boot gate (collect-all).
- *(http)* Route model binding: `route.bindings` registry service with
  per-model resolvers registered at boot (`GRAPH-BINDING-RESOLVER` gate);
  the edge injects `_bindings.<param>` after the path/query/body merge so
  bodies cannot forge bindings; malformed id / miss / cross-tenant all 404.
- *(http)* Pagination injection: GET graph routes parse `page`/`per_page`
  (clamped to `MAX_PER_PAGE` 100; `page=0` -> 422) and inject `_page`;
  appointments `list` emits the `page` meta block (page, per_page, total,
  has_more).
- *(http)* Manifest FormRequest validation at the edge: `[[validation]]`
  specs run collect-all before CommandBus dispatch (422 envelope with
  `fields` meta); the `date` rule accepts minute-precision timestamps.
- *(http)* Deprecated routes (`deprecated = true`) emit `Deprecation: true`
  header + envelope meta (L72); anonymous reach is restricted to public
  routes whose handler plan opts out of authorization.
- *(http)* `TypedHandler<I, O>` typed bridge (keel-command) plus
  `Validated`/`Resource` view-model adapters (keel-http) as the opt-in
  typed dispatch pattern.
- *(cli)* `keel route:cache` / `keel route:clear`: write/delete the pinned
  route artifact `storage/framework/routes.json` (resolved chains, bindings,
  validators + manifest content hash + `MODULE_ABI`); boot always recompiles
  the graph and refuses a stale or corrupt artifact (stricter than Laravel).
- *(cli)* `keel check` now also compiles the platform graph and resolves
  every route's middleware chain (`GRAPH-MW-UNKNOWN`).
- *(codegen)* OpenAPI emission carries `[[validation]]` constraints
  (required, minLength/maxLength, minimum/maximum, enum via one_of, format
  hints) and native `deprecated: true`.

**Wave 2 — routing completion, web plane, views, request/response, errors, assets:**

- *(routing)* Route planes and edge dispatch (Laravel routing parity):
  `plane = "api"|"web"` per route/group/root route file, verb dispatch with
  auto-HEAD (body stripped, 8 MiB cap), auto-OPTIONS with `Allow`, 405 +
  `Allow` on verb mismatch, `method = "ANY"` expanding to the full verb set
  at registration, `RouteGate` host/domain/subdomain matching before `auth`,
  signed + temporary/one-time signed URLs (HMAC-SHA256; fail-closed 500
  without `app.key`, spent link -> 404), parameter constraints as a routing
  predicate (closed kinds + pattern mini-grammar, no regex crate; mismatch ->
  404), and `[url] defaults` for `resolve_url`.
- *(registry)* Root route files (`routes/web.toml`/`routes/api.toml` merged
  at boot, `GRAPH-ROUTEFILE-OP`), `[[route_groups]]`
  prefix/middleware/plane inheritance (`GRAPH-GROUP-UNKNOWN`,
  `GRAPH-FALLBACK-DUP` max-one-per-plane), resource/singleton expansion
  (`resource`/`apiResource`/`singleton` shapes with `only`/`except` verb
  filters), `UrlSection` URL defaults — all parse-time with collect-all
  boot gates.
- *(views)* `keel-views` template engine: interpreted AST, full
  Blade-familiar directive ledger (`@extends`/`@section`/`@yield`/`@parent`,
  `@include*`, `@component`/`@slot`/`@props`, `@if`/`@unless`/`@foreach`/
  `@for`/`@forelse`, `@once`/`@push`/`@stack`, `@csrf`/`@method`/`@error`/
  `@lang`/`@js`, attribute helpers), custom directive + conditional
  registries, package namespace resolver, compiled-AST cache (mtime +
  content hash); `@php`/`@while` refused as SUPERSEDED (no PHP eval).
- *(http)* HTML routes (`response = "html"` renders the declared view with
  the operation result as context) and web-plane error rendering (error
  views for HTML clients, envelope for JSON, RFC-7807 `problem+json`
  opt-in, `app.debug` gate hides internals).
- *(http)* Response kinds at the edge: `json` (default envelope), `html`,
  `redirect` (validated status + one-request flash), `download`/`file`
  (StoragePort attachment, sanitized filename), `stream` (chunked NDJSON
  flush), `no_content`; plus per-route `Cache-Control` policy with
  ETag/conditional-GET 304.
- *(http)* Static assets for `public/`: percent-decoded path resolution,
  traversal refusal, canonicalized prefix check, fingerprinted files get
  `immutable` (else `no-cache`), Vite `manifest.json` reader + `@asset`
  directive, not-found fallback rendering the error view or envelope.
- *(cli)* `keel route:list --name/--path/--plane` filters (case-insensitive
  substring, validated plane) with plane/group/version/deprecation columns,
  and the `keel view:cache` / `keel view:clear` compiled-view artifact
  cycle.

### Testing

- *(http)* `http_integration` Wave 1 battery: 422 field meta, public vs
  authenticated reach, binding miss/malformed/cross-tenant 404 + cancel on
  hit, pagination clamp + `page=0` 422, deprecation header/meta, throttle
  429 + Retry-After.

**Wave 2 test battery:**

- *(routing)* `routing_edge_integration`: ANY dispatch across every verb,
  auto HEAD/OPTIONS, verb mismatch -> 405 with `Allow`, domain/subdomain
  gates before `auth`, one-time signed redemption (-> 404), constraint
  mismatch -> 404 for every kind.
- *(views)* `views_integration` (view render with operation context, auth
  context, web-plane 404 error view, JSON clients keep the envelope,
  engine-less degradation) plus engine facets (escaping XSS vectors, layout
  inheritance, component slots, `@once`/`@push` stacks, `@forelse` empty
  branch, compiled-cache hit/invalidation, custom directive + conditional,
  package namespaces) and `error_rendering_integration` (web-plane error
  views, `problem+json` option, `app.debug` open/closed).
- *(registry)* Wave 2 gate units: `GRAPH-PLANE`, `GRAPH-GROUP-UNKNOWN`,
  `GRAPH-CONSTRAINT-PARAM`, `GRAPH-CONSTRAINT-KIND`, `GRAPH-FALLBACK-DUP`,
  `GRAPH-ROUTEFILE-OP`, `GRAPH-CHANNEL-CAP` (collect-all), resource +
  singleton expansion (`only`/`except`, no `{id}`), and `excluded_middleware`
  chain removal.
- *(static)* `static_assets_integration`: traversal refusal, encoded-path
  refusal, fingerprint → `immutable` vs `no-cache`, `@asset` directive,
  not-found fallback.
- *(cli)* `route_list_filters_carry_the_parity_columns` and
  `view_cache_cycle_compiles_and_clears` (keel-console).

### Changed

- *(workspace)* **Wave 2 crate renames** (crates.io name-squat recovery):
  `keel-core` → `keel-foundation`, `keel-sessions` → `keel-session`,
  `keel-events` → `keel-event`, `keel-cli` → `keel-console` (directory moved
  `tools/keel-cli` → `tools/keel-console`; `[[bin]] name = "keel"` unchanged).
  Package names, workspace dependency keys, member manifests and every import
  (`keel_core` → `keel_foundation`, etc.) were swept together, plus the doc
  references in `platform/docs/*`, `platform/PUBLISHING.md`, `docs/rust/*`.
  The `publish = false` gate and the Wave 2 comment are removed from all four
  manifests, unblocking the Wave 2 publish wave.
- *(release)* **Wave 2 publish-dry triage**: the `xtask publish` guard now
  passes — the seven Sentinel/integrity crates documented as *internal-only
  until a release wave* had their `publish = false` gate lifted (`keel-metrics`,
  `keel-telemetry`, `keel-tracing`, `keel-pipeline`, `keel-buffer`,
  `keel-export`, `keel-integrity`), `keel-api` gained `publish = false` (demo
  API host hard-wiring `keel-mod-appointments`, which stays gated), and
  `--dry-run` classifies the first-publish bootstrap gap (unpublished
  workspace-internal deps) as `deferred` instead of failing — guard
  violations, manifest/file errors and registry problems still fail the run.
  Workspace: 68 members, 61 publishable, 7 gated.

### Fixed

- *(clippy)* `too_many_arguments` on `MiddlewareCatalog::validate_route` — the
  seven per-route parameters collapsed into a `&RouteSpec` (single caller).
- *(clippy)* `ptr_arg` on `apply_groups` (`&mut Vec<RouteSpec>` → `&mut [RouteSpec]`),
  `doc_lazy_continuation` on the `RouteSpec::constraints` doc, and
  `explicit_counter_loop` in the views parser (`starts`).

## [0.1.0] - 2026-08-22

### Features

- *(release)* First public crate: **keel-analyzer 0.1.0** — architecture
  analyzer enforcing the platform dependency matrix (gate G07).

### Build

- *(release)* Release-engineering groundwork: crates.io metadata
  (repository/readme/keywords inheritance, docs.rs config), per-crate READMEs,
  MIT + Apache-2.0 license files, versioned internal workspace dependencies,
  and `publish = false` gating for internal-only and Wave-2-blocked crates.
- *(release)* `xtask publish` (topologically ordered, retries, dry-run,
  `--only` subset, machine-readable summary for CI) and `xtask bump`
  (lockstep version bump with count validation).
- *(release)* Supply-chain gate: `deny.toml` (cargo-deny v2) — advisory,
  license, ban, and source policies with a documented MPL-2.0 exception.
- *(release)* `keel-publish.yml` workflow: ubuntu+windows verify matrix,
  MSRV 1.85 check, cargo-deny, semver gate, publish, registry smoke test,
  release tag `keel/platform-vX.Y.Z`, changelog regeneration.
- *(release)* Continuous publishability signal (`publish --dry-run`) on the
  main branch in `keel.yml`.
- *(release)* Conventional Commits convention + git-cliff changelog
  automation (`cliff.toml`, `just changelog`).

### Documentation

- *(release)* `PUBLISHING.md` (release flow, token hygiene, wave status,
  bump/yank/troubleshooting) and `runbooks/keel-release.md` checklist.
